  test output against a grep -F literal in which I had escaped a forward slash
  ("material\/1"), a sequence that appears nowhere in ExUnit's output. The mutation
  had in fact failed three tests. Re-run with the correct literal: KILLED by
    1) 7.6 ADVERSE — material/1 is documented 'Never an error' ...
    2) the fallback is conservative — an input it cannot read never draws stronger than fog
    3) the fallback exists and is fog, so the two claims above are not in tension
  Recorded because a harness that can report a false SURVIVED can also report a
  false KILLED, and the reader is entitled to know which kind of instrument this was.
