QUICK GUIDE — how to run the show (click to expand)
⚠️ This console is System 1 — the colony SOURCE + a DEV preview. Its GO LIVE drives a LOCAL restreamer (rtmp://127.0.0.1:1935 → your own YouTube/Twitch test), NOT the worldwide broadcast. The worldwide go-live is System 2 (production/) — see docs/STUDIO_SYSTEMS.md.
  1. Pick a look: click any template below → it loads into the green PREVIEW monitor (what you're about to show). Hover a card for what it is.
  2. Put it on air: press TAKE to transition preview → program. Double-click a card to hot-cut straight to air. For a truly smooth monitor, click OPEN SMOOTH 30fps MONITOR.
  3. Cameras: set roles A/B/C to any camera or live remote slot. The PC camera is always video-only; remote cameras carry their own mic. Pick the on-air voice.
  4. Content: load a web page, roll a YouTube clip (full / side-by-side / PIP), or bind a shared window into a slot for DESK/SHARE/TEACH.
  5. Remote sources: on another computer open https://…:8443/ — pick a Camera / Screen / Video into a slot; it appears in the role dropdowns (● = live).
  6. Overlays & air: set the lower-third / ticker / caption (kept honest by the claim fence). To broadcast: start the restreamer, type CONFIRM, press GO LIVE. The banner + the lab glass badge show OFF / REHEARSAL / LIVE STREAMING / LIVE LIVE.
