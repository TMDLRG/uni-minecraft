What this is

This records your answer to a question the plan actually asks, into evidence/decisions.ndjson — append-only and hash-chained. Until this page existed, every one of the 85 rows in the comment ledger and every co-sign in the control-plane ledger was written by an agent. Your answers lived in a chat window, which is not an artifact.
Claim level: presence_evident — this does not prove it was you. The endpoint checks that the request came from this box, as a loopback name, with a header a cross-site page cannot forge. None of that is a human: an agent running on this machine satisfies every one of those checks and could write the same row. What the ledger does give you is that a row cannot be quietly changed or removed later. Tamper-evident, not authenticated — and no gate anywhere is allowed to read this file as permission to act.
loading the server's own caveat…
It records. It never acts. Answering “go ahead” to a stop writes down that you said go ahead. It does not do the thing. Nothing on this page can go live, mint presence, or write the gate ledger.
If this page is gone: a watchdog restarts TRACK within about five seconds of it dying — viewer\track\track_watchdog.ps1, supervised from your Startup folder. That is crash-restart, and it is proven. Reboot-survival is NOT proven — the Startup entry exists but this machine has not been restarted since it was installed, and an entry that exists is not an entry that fired. If TRACK is ever down and stays down, start it with node viewer\track\track_server.cjs from the repository root. Your answers are in evidence/decisions.ndjson either way; this page is a way in, not where they live.
